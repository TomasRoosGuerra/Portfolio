How I work

Research, prototype, test, ship, measure.

  1. 01

    Research

    I start with people, not screens: interviews, affinity mapping, personas and a hard look at competitors.

  2. 02

    Prototype in code

    Claude Code, Cursor and Figma Make turn ideas into working prototypes in days, not weeks.

  3. 03

    Test before building

    User tests run before development starts, so engineering builds decisions that already hold.

  4. 04

    Ship

    I work side by side with engineers and PMs, write the microcopy myself and keep design and code in sync through the design system.

  5. 05

    Measure

    GA4, PostHog and Amplitude show what changed. That feeds the next round.
